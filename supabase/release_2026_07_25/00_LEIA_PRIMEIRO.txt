VALORAE — SQL ATUALIZADO PARA SUPABASE — 2026-07-25

Este conjunto foi gerado após comparar o APK enviado, o Proxy enviado e os SQLs antigos 01, 02, 04A, 04B, 04C e 05.

EXECUÇÃO
1. Publique primeiro o Proxy corrigido fornecido junto desta revisão.
2. No Supabase, abra SQL Editor > New query.
3. Execute os arquivos 01 a 11, um por vez, exatamente na ordem numérica.
4. Espere cada arquivo terminar antes de executar o seguinte.
5. O arquivo 12 é opcional e somente leitura. Execute cada bloco separadamente se quiser investigar consumo.

IMPORTANTE
- Não execute novamente os SQLs antigos 01, 02, 04A, 04B ou 04C depois deste conjunto.
- Os scripts são idempotentes: podem ser aplicados sobre o banco existente e também completam estruturas ausentes.
- Transações, snapshots e proventos existentes são preservados.
- A limpeza remove apenas telemetria do monitor, estado operacional efêmero e backups redundantes antigos.
- As funções mantêm a assinatura esperada pelo APK/Proxy, mas p_backup é ignorado para impedir duplicação integral de payloads.
- O monitor e o estado operacional do Proxy corrigido funcionam em memória; não dependem das tabelas valorae_monitor_events ou valorae_runtime_shared_state.
